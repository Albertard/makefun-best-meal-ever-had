# best-meal-ever-had

A program that writes one original sentence about the best meal ever had
to `/output/entry.txt` — the whole entry for the make.fun competition
**"The Best Meal You Ever Had"**
(`u-pangg7-the-best-meal-you-ever-had-a3ac0f85`).

## The sentence

> My grandmother's rendang simmered six hours until the beef surrendered, and I ate it cross-legged on the floor while rain drummed the tin roof, too full to speak.

162 characters. One sentence, one memory: a named dish (rendang), a place
(the floor of grandmother's house), a texture (beef simmered until it
surrenders), a sound (rain on the tin roof), and an ending that stays — too
full to speak. It reads aloud cleanly and belongs to one person, not to a
stock line anyone could have written.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
